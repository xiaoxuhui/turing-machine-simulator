# 图灵机实验台 v0.3.0 开源整改实施计划

## 目标

按《需求与测试用例》完成安全、可靠性和公开协作整改，保持 v1 项目和现有模拟器行为兼容。

## 执行原则

- 先固定攻击/竞态/无效导入回归，再接入页面。
- 每个逻辑单元单独提交。
- 每阶段测试通过后再进入下一阶段。
- 不混入许可证选择、历史重写、远端操作或整页重写。
