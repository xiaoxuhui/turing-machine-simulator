# 需求与测试用例：跟随读写头模式的滑动时长随速度自适应

## 背景
跟随读写头模式下，纸带中心随读写头移动时，用 CSS `transform` 过渡实现平滑滑动（见 `设计文档-跟随平滑.md`）。
原实现把过渡时长**硬写固定为 150ms**。但步进节奏由目标速度决定（每步间隔 ≈ `1000 / 速度` 毫秒），固定时长与实际节奏脱节，产生两类问题：
- 速度低（如 1 步/秒）：每步间隔 1000ms，却只滑 150ms，余下 850ms 静止 → 观感是「先停一会，再猛地跳一步」。
- 速度高（如 10 步/秒）：每步间隔仅 100ms，过渡 150ms 比间隔还长 → 上一段滑动未完成就开始下一段，积压、抖动、刷新不过来。

## 需求
- R1 过渡时长随目标速度自适应：约等于单步间隔的 90%（`duration ≈ (1000 / 速度) * 0.9`）。
- R2 慢速时滑动连续、无明显停顿：速度 1 时时长接近整段间隔。
- R3 快速时不积压：速度高时时长不超过（且远小于）单步间隔，滑动能跟上演进。
- R4 边界安全：速度异常（0、负、NaN、超范围）时不崩，回退到合理默认值。
- R5 非跟随模式（固定 0 / 随意拖动）行为不变：随意拖动仍由指针即时驱动，无过渡。

## 测试用例
| 用例 | 输入(步/秒) | 期望时长(ms) |
|---|---|---|
| T1 慢速连续 | 1 | 900（≈1000*0.9，封顶） |
| T2 默认速度 | 5 | 180（200*0.9） |
| T3 中速 | 10 | 90（100*0.9） |
| T4 快速 | 100 | 9（10*0.9，封底 8 以上→9） |
| T5 极速 | 1000 | 8（1*0.9 低于下限，封底 8） |
| T6 非法值 | 0 / -3 / NaN | 回退默认（取 speed=1 → 900 或受保护值） |
| T7 集成 | 选「跟随读写头」、改速度为 1 后运行 | 每步滑动时长≈900ms，连续前进、无长停顿 |
| T8 集成 | 选「跟随读写头」、改速度为 50 后运行 | 每步滑动时长≈18ms，快速且不过度积压 |
