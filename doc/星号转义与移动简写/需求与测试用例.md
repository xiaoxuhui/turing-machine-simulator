# 星号转义与移动简写

日期：2026-11-05。状态：PENDING。

用户要求纯星号字符用多一个星号表示：`**` 为字面 `*`，`***` 为字面 `**`，以此类推；写入字段单个 `*` 仍保持符号。箭头后只有“目标,一项”时，优先识别 R/L 为方向，其余作为写入。完整写入 R/L 使用 `R,*`、`L,*`。

- U01：仅一项的 R/L（包括原方向语法支持的小写）保持符号、相应移动；其它符号写入并默认 N，N 本身作为写入符号。
- U02：任意长度纯星号按多一个字符转义，读/写/函数符号参数保持一致；单个读取星号仍按字面星号兼容，不是通配符。
- U03：写入及方向都为星号仍保持符号、不移动；完整规则写入 R/L、留空和函数调用都正确。
- U04：结构化规则表、实际展开、复制后解析、示例数字化/提取/展开不丢失字面星号，修改其它字段不能改变写入内容。
- U05：实际图灵机执行与真实浏览器验证短移动、写字母 R/L、连续写多星号和重新读取，错误方向仍定位。
