# 自定义导出文件名

状态：PENDING。2026-11-01 用户反馈导出时不能自定义名字。

点击导出项目或导出记录后，先在页面内填写文件名，再确认下载。预填原默认名称；省略扩展名时补上 .json 或 .csv。取消不下载、不修改编辑器。空名称及文件名不允许的字符应就地提示。

- U01：项目使用中文自定义名称，下载的 JSON 内容与当前项目一致；省略扩展名自动补全。
- U02：执行记录自定义 CSV 文件名，已有扩展名不重复添加，内容保持不变。
- U03：取消、Escape 均关闭弹窗且不下载；空名称及路径字符不能提交。
- U04：键盘 Enter 可确认，焦点进入文件名输入框；窄屏弹窗完整可用。
