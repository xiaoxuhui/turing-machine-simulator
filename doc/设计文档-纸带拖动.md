# 设计文档 — 纸带可鼠标左右拖动（feature: draggable-tape）

- **版本**：v0.4.0-feature
- **状态**：草稿
- **实施策略**：纯函数 + 独立交互模块 + 主程序集成，分层提交。

## 1. 设计目标

- **D1 可拖动**：在 `#tape` 上按住并左右拖动即可平移纸带窗口。
- **D2 初始为 0**：`tapeScroll` 默认 0，机器未运行时窗口以位置 0 为中心。
- **D3 兼容现有视角**：拖动偏移叠加在 `follow-head` / `fixed-zero` 基准中心之上。
- **D4 可重置**：`createMachine` / `resetMachine` 时 `tapeScroll` 归零。
- **D5 不破坏既有逻辑**：仅新增状态与事件接线，不改变 `TuringMachine`、`tile-puzzle`、运行/单步等逻辑。
- **D6 可测试**：像素→格子换算抽成纯函数；拖拽交互抽成可在 jsdom 下单测的模块。

## 2. 模块分层

```
src/core.ts            → panFromDragDelta(startScroll, deltaX, pitch): number   [纯函数, 可单测]
src/tape-drag.ts       → attachTapeDrag(tapeEl, { getScroll, setScroll, getPitch }): void  [交互模块, 可单测]
src/main.ts            → 新增状态 tapeScroll; 在 renderTape 用 center=基准+tapeScroll; 调用 attachTapeDrag; 重置归零
src/styles.css         → .tape { cursor: grab }  .tape.dragging { cursor: grabbing; user-select: none }
```

## 3. 关键算法

### 3.1 像素 → 格子换算（纯函数）
```ts
// 向右拖动 deltaX>0 → 内容右移 → 显示更小的位置 → tapeScroll 减小
export function panFromDragDelta(startScroll: number, deltaX: number, pitch: number): number {
  if (pitch <= 0) return startScroll;
  return startScroll - Math.round(deltaX / pitch);
}
```

### 3.2 拖动交互（attachTapeDrag）
- `pointerdown`（在 `#tape` 内）：记录 `startX = e.clientX`、`startScroll = getScroll()`；`tapeEl.setPointerCapture(e.pointerId)`；加 `.dragging` 类。
- `pointermove`（元素上，已捕获）：`deltaX = e.clientX - startX`；`setScroll(panFromDragDelta(startScroll, deltaX, getPitch()))`；触发重渲染（由 `setScroll` 的调用方负责 `renderTape()`）。
- `pointerup` / `pointercancel`：释放捕获；移除 `.dragging`。

> `getPitch()` 在拖动开始时由调用方测量：取 `#tape` 中相邻两个 `.cell` 左边缘之差（`getBoundingClientRect().left` 相减），保证在不同分辨率/媒体查询下换算准确。

## 4. 数据流

```
用户拖动 #tape
  → pointerdown: 记录起点 + 设捕获
  → pointermove: tapeScroll = panFromDragDelta(...)  →  setScroll 回调内 renderTape()
  → pointerup:   释放
renderTape(): center = tapeWindowCenter(mode, head) + tapeScroll
             渲染 [center-8 .. center+8] 共 17 个格子
```

## 5. 状态变更（main.ts）
- 新增模块级变量 `let tapeScroll = 0;`
- `renderTape()` 中 `const center = tapeWindowCenter(mode, head) + tapeScroll;`
- `createMachine()` 与 `resetMachine()` 开头 `tapeScroll = 0;`
- 初始化时 `attachTapeDrag(byId("tape"), { getScroll: () => tapeScroll, setScroll: (v) => { tapeScroll = v; renderTape(); }, getPitch })`

## 6. 风险与权衡
- **不引入滚动容器**：保持现有 `justify-content:center` 的 17 格窗口，拖动直接改 `center`，实现简单、无溢出副作用。
- **follow-head + 拖动**：运行时 head 移动会改变基准，`tapeScroll` 偏移会叠加保留；如需「钉在 0」可用 `fixed-zero` 模式，二者行为清晰。
- **触摸**：Pointer 事件天然覆盖触摸与笔；无需额外处理。
