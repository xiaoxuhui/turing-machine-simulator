# 寄存器加法器与跳转简写设计

2026-11-04，VERIFIED。

将普通转移的两字段省略格式在平面解析器中统一归一化为 写入=读取、移动=N。函数编译器调用同一底层解析，不再单独限制简写目标必须是函数。普通目标、函数目标、终态使用原有目标解析及执行逻辑，计为一次保持符号/位置的转移。

原始用户程序放在 src/register-adder.tm，由独立示例模块提供机器配置，注册在现有一进制分组。原样保留规则与函数结构；有注释版添加阶段说明，所有版本沿用全局示例选项。通过真实纸带运行验证数值及最终工作符清理。

原稿测试暴露自循环 0.1,1->0.1,1,L 被误跳到后方只处理 | 的同名表达式。混合函数及顶层自循环只在后续组包含相同读取键时沿用顺序表达式跳转，否则保留当前实际入口。普通未知目标直接保留其状态名，运行时缺规则，而不是跳到后续裸函数。

最终不采用对原稿 L 的改写，示例与 raw 文件一致。默认 1+11，记录原稿 11+ 的结果差异。注释说明输入复制、寄存器增减及收尾，普通写法与简写都继续支持。
