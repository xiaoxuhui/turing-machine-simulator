## 关键风险与对策
- **Form C 绝对路径白屏**：构建用 `vite build --base=./`（CLI 覆盖，不改 `vite.config.ts`）。自检：`grep -oE '(src|href)="[^"]+"' dist/index.html` 不应出现以 `/` 开头的资源路径。
- **gradlew CRLF**：根 `.gitattributes` 钉 `android/gradlew text eol=lf`。
- **Kotlin 常量前向引用**：`ASSET_DOMAIN` 必须先于 `PAGE_URL` 声明（模板已正确排序，照搬即可）。
- **CI 看不到日志**：workflow 内置把 `^e:` 错误写成 `::error` 注解；查状态用 `curl` + GitHub API 而非 WebFetch（有 15 分钟缓存）。
