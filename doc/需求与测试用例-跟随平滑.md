# 需求与测试用例：跟随读写头视角平滑移动

## 背景
「纸带视角」提供三种模式：跟随读写头 / 固定在 0 / 随意拖动。
- 「随意拖动」已支持平滑跟手（亚格 transform 连续跟随）。
- 「跟随读写头」目前每执行一步都把可视窗口中心瞬间跳到新读写头位置，纸带一格一格硬跳，观感生硬。

本需求：把「跟随读写头」视角也改为**平滑移动**——读写头移动时，纸带以过渡动画连续滑到新位置，而非逐格跳变。

## 功能性需求
- **R1 平滑跟随**：在「跟随读写头」模式下，当读写头位置相对上次渲染发生变化时，纸带应**连续滑动**到新中心，而不是瞬间跳格。
- **R2 与现有拖动解耦**：「随意拖动」模式的平滑跟手行为保持不变；两者不互相干扰。
- **R3 其它模式不受影响**：「固定在 0」下读写头移出窗口时行为不变（边缘指示、headState 提示保持原样）。
- **R4 不跳变初始化**：新建机器 / 重置 / 切换视角后的第一次渲染不应触发从旧中心滑入的动画（直接定位于新中心）。

## 非功能性需求
- **N1 性能**：动画仅用 CSS transform 合成层，不触发整段重排（cells 仍按需重渲染）。
- **N2 可测**：位移计算抽成纯函数，可单测。

## 测试用例（单元）
1. `headFollowShift(0, 1, 58)` 返回 `58`（向右 1 格 → 初始瞬时位移 +1 格）。
2. `headFollowShift(5, 3, 60)` 返回 `-120`（向左 2 格 → 位移 -120px）。
3. `headFollowShift(a, a, 58)` 返回 `0`（未移动 → 无位移）。
4. `headFollowShift(0, 10, 0)` 返回 `0`（pitch=0 兜底，避免除零/异常）。

## 验收（手动，内置浏览器）
- 选「跟随读写头」，点「运行」或连点「单步」：纸带应平滑滑动跟随读写头，不再一格一格硬跳。
- 选「随意拖动」并拖动：平滑跟手行为不变。
- 切到「固定在 0」、再切回「跟随读写头」、或重置后：第一次渲染不滑入。
