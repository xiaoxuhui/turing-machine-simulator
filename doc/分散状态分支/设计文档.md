# 分散状态分支设计

2026-11-02，VERIFIED。

保留原有物理语句位置，新增状态分支组分析：同状态的后续语句若读取符号不重复，复用当前组的实际入口；若出现重复读取键，则开始新的独立表达式组。仅合并入口，不搬动规则，不改变每条规则对应的函数搜索和续接位置。

顶层脚本与混合函数体共同使用 branchEntries 分组结果。顶层先将首个裸调用前的普通声明作为初始分支组，后续非重复符号也可复用声明的原入口；顶层首次状态保留原名，后续独立组才分配后缀。局部首次入口与后续组隔离逻辑保持。已有纯规则函数继续按原解析和重复检查。

对用户给出的 0,|->output 做黑盒执行回归，并覆盖扫描 11|、重复调用、返回及原有连续表达式。
