# 高速直接移动与单步动画测试报告

- 日期：2026-10-26。
- 结论：连续运行 >10 直接移动，≤10 平滑；手动单步固定 180ms，与目标速度无关。只改显示，不改变转移执行或调度算法。
- 修正范围：用户澄清后，明确将“单步”和“运行”的动画来源分开；运行结束或暂停后点击单步仍走手动动画。

## 自动测试

修改前新增阈值断言，`vitest.cmd run tests/core.test.ts` 得到 24 通过、2 失败：11 时返回 81.818ms、1000 时返回 8ms，而非期望 0。修改后并加入手动动画独立性断言，执行：


动画测试覆盖 10=90ms、11/100/1000/5000=0，以及无效输入回退；手动模式在 1、5、10、11、100、1000、5000、0、NaN 下均为 180ms。原有核心、调速同步、持久化和拖动测试继续通过。
