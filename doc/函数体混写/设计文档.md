# 函数体混写：设计文档

共享规则/调用按源码位置分组成 Statement 的逻辑。仅混合函数使用局部语句表，纯规则函数、纯组合函数沿用已有行为。

每个混合函数实例预分配局部规则组入口；同名重复组拥有独立入口。按源码倒序展开裸调用以接好 continuation。目标为函数时优先使用后续同名（或同一别名绑定函数）的调用入口；不存在则编译当前位置调用。目标为普通状态时先选后续最近同名规则组，找不到则局部第一组，保留循环；未知局部状态保留为缺规则状态。

Context 记录语句入口、局部状态映射，localState 支持 ret 返回和公开扩展。入口使用函数头的初始状态；函数正常出口接 continuation，显式 ret 接父或外部对应状态。每次顶层/父调用仍有隔离命名，不增加运行时栈或计算捷径。

新增独立函数教程示例，解释裸调用后面接表达式以及条件跳过中间代码，不替换用户当前编辑内容。
