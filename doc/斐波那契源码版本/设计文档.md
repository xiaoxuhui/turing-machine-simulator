# 斐波那契源码版本：设计文档

在fibonacci-example.ts内维护用途名到原始数字名的双射，以及各状态所属的四个阶段。所有版本由现有54条规则生成，避免维护八份不同算法。

有函数版将四阶段封装为规则函数；阶段间跳到公开局部状态，保留原循环图，不使用递归调用和额外N控制步。数值名称可用于局部状态；各函数声明导出状态供跨阶段引用。默认函数入口为初始化，配置普通停机态HALT用于函数展开但原规则不指向它，仍持续运行。

示例面板的两个选项仅对fibonacci显示，与注释风格正交。加载时由选择构建ExampleProject，然后复用exampleSource及fillProject。
