# 设计：转移规则默认值

日期：2026-11-04。状态：COMPLETE。

在 core 的唯一普通转移解析器中允许最后两个逗号字段分别省略或为空；写入 trim 后为空时采用 readSymbol，方向为空时采用 N。移动非空仅允许 L/R/N，不根据写入内容猜测方向。函数编译器、关卡、导入均继续复用此解析器。

规则表增加默认不移动选项与写入保持提示；表格编辑仍通过文本解析并重新创建实际机器。编译后的规则继续显式展示最终写入和方向，便于核对。

两字段省略扩展了合法语法，原来使用缺失方向作为非法输入的测试改用真正非法方向。单个写入符号可包含点，不能再将 `l.L` 无条件视作格式错误。
