# 转移规则默认值

日期：2026-11-04。状态：PENDING。

用户要求写入、移动可以各自留空；写入默认保留读取符号，移动默认 N。显式写入和 L/R/N 保持原意，普通状态、函数、终态、关卡共用解析器。

- U01：`q,1->end`、`q,1->end,`、`q,1->end,,` 均保留 1、不移动。
- U02：`q,1->end,0` 与 `q,1->end,0,` 写 0、不移动。
- U03：`q,1->end,,R` 保留 1、右移；空格和小写方向正常。
- U04：字段按逗号位置解释，`q,1->end,R` 写入字符 R，方向 N。
- U05：非法方向、缺少目标、多余字段继续显示行号和原因；完整写法不变。
- U06：函数内的省略字段与写全规则展开、运行等价；导入使用同一默认值。
- U07：真实浏览器编辑规则表，清空写入、选择默认移动后运行，与文本及实际规则一致。
