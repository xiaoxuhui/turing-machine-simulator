# 三段式关卡阶段总结 v0.5.0

## 已交付

- 课程从 8 关扩展到 16 关，并划分教程、闯关、高难三个章节。
- 新增 2 道教程过渡关、4 道综合闯关和 2 道高难算法关。
- 侧栏展示章节说明、章节完成数和三级难度标记。
- 完整答案继续只存在于测试代码，生产页面不提供载入答案入口。

## 验证

- 自动化测试：98/98。
- Android 壳层测试：8/8。
- 真实桌面浏览器：章节、进度、旧存档兼容与控制台检查通过。

## 架构说明

- `campaignSections` 是章节顺序与文案的唯一来源。
- `CampaignLevel.section` 和 `difficulty` 驱动页面分组，不把章节逻辑硬编码进渲染层。
- 保存格式继续使用 v1，仅按已知关卡 ID 过滤，因此无需破坏性迁移。
