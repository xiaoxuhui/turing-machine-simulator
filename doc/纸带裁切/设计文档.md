# 纸带裁切设计

日期：2026-10-26。

外层 `.tape-shell` 维持整体装饰和状态；新增 `.tape-viewport` 作为固定、居中的裁切窗口，内部 `#tape` 才做平移。17 格宽度按原有桌面 58px、窄屏 52px 及 1px 边框重叠计算；窗口不大于容器宽度。把外壳的部分垂直留白移入窗口，使编号和箭头也在裁切范围内但不被正常截断，整体高度不变。只恢复此前动画并增加显示边界，不修改计算规则、速度数值或调度。

最终澄清：手动单步固定 180ms，连续运行恢复原速度自适应时长（高速仍有 8ms 下限），不再有速度阈值。跟随显示的初始位移限于正负一格；机器仍执行全部转移，只有画面不再按累计多格位移飞出窗口。
