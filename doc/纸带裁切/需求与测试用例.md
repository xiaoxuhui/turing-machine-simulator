# 纸带裁切需求与测试用例

日期：2026-10-26；用户要求撤销上次动画调整，同时快速移动不把格子显示到窗口外。

- C01：按用户最终澄清，撤销速度大于 10 时直接移动的策略；连续运行恢复速度自适应平滑移动，手动单步保留固定平滑动画，不随目标速度改变。
- C02：新增不参与 transform 的固定纸带窗口，最大宽度正好包住 17 格；快速滑动、批量多格移动或拖动时，越过窗口的部分隐藏，不进入两侧空白区。
- C03：窗口保留格子编号、头部箭头和状态文字；窄屏窗口收缩且不产生横向溢出；固定 0 与自由拖动仍可用。
- C04：自动测试覆盖结构与边界样式；真实浏览器检查 10/11/1000、手动单步和拖动及桌面/窄屏裁切。
- C05：连续运行一帧可能执行多次转移，但显示位移最多一格，防止读写头随整排格子飞出窗口；计算步数与结果不变。
