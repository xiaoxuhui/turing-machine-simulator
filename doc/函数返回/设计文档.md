# 返回与状态导出设计

扩展现有规则编译器，仍不引入运行时调用栈或计算捷径。函数默认返回地址改为显式第二状态；普通规则的函数调用使用该地址。嵌套规则调用将子函数退出名映射到父作用域对应状态，找不到时使用外部原名；旧单状态调用保留此前续接策略。

函数头额外项解析为局部函数绑定，所有调用引用在图检查与展开时先解析绑定；编译前检查递归和深度。顺序列表编译的每次调用仍由列表给出续接地址，最后一次可续接已有外部退出规则。所有生成局部状态仍使用防碰撞前缀及实例编号。

`返回状态` 只声明公开入口，不生成额外执行步骤。每个函数在默认返回上下文有固定副本，公开别名 `函数名.局部态` 映射到该副本的状态；初始/退出的导出映射到真实入口/续接地址。普通规则的源、目标及初始状态选择可解析这些别名，不允许通过函数前缀访问未导出的局部态。导出不暴露其它临时调用实例，避免不同续接上下文串用。合并所有转移后按状态/读取符号检查重复，不能静默覆盖。

外部为导出状态补写的规则会复制到每次调用的相应局部态，出口和同函数的公开目标按当前调用重写，避免顺序多次调用只有第一份生效。组合函数没有实体局部规则，仅允许导出初始或退出状态。
