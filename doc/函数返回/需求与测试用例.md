# 函数返回、子函数与状态导出

日期：2026-10-27；用户要求直接实现，不再反复确认。

- R01：普通规则调用 `函数(q0,q1)` 后，退出进入外部 q1 继续执行，不再一律 HALT；函数初始状态选择也使用该默认返回状态。
- R02：顺序调用列表可以与外部普通规则共存；列表决定启动顺序，最后一个函数若有对应外部退出规则则接过去，否则保留原先停机行为。旧单状态函数及现有顺序调用结果兼容。
- R03：q1 后支持自定义子函数：直接列函数名，或 `局部名=已有函数名`。函数体可用这些名称调用子函数；规则调用的子函数退出后，优先继续父函数内同名局部状态，否则进入对应外部状态。这里只绑定函数，不宣称支持任意值参数。
- R04：缩进的 `返回状态 q2, q3` 导出内部使用的状态，外部以 `函数名.q2` 使用。导出属于函数的默认返回上下文，不指向顺序调用的临时副本；每次调用仍有独立内部命名。
- R05：禁止未导出状态访问、重复导出、未知导出、非法绑定/同名冲突、合并后重复转移及递归；同名局部态与其它函数、外部状态隔离。
- R06：页面说明和示例可直接运行；展示导出名，导入/保存及刷新保留新源码。全部编译为普通纸带转移，计算核心与速度不变。
- R07：用真实机器验证外部续接、父函数续接、组合/重复调用、子函数别名、导出状态作为目标/来源/入口及同名隔离；浏览器运行并刷新验收。
