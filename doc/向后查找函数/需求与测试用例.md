# 向后查找函数：需求与测试用例

日期：2026-10-30。用户要求：状态目标为函数时，检查后续表达式序列，有同名裸调用就转至该位置；不存在则当前位置调用，完成后继续下一行。

- U01：在顶层表达式中跳到 f，后面有裸调用 f 时，跳过中间表达式及其它函数，从该 f 开始，完成后继续它下面。
- U02：只选择后面最近的同名调用；前面的同名调用和后面的其它函数不算。
- U03：后面没有同名调用时，保持原来的就地调用及续行。
- U04：首个裸调用前的顶层规则也使用上述查找方式；ret 保持显式返回语义。
- U05：真实浏览器验证跳过中间代码及就地调用两条路径。全部现有测试执行，任何受影响行为单独分析。

函数定义仍是声明，查找对象为后续顶层表达式序列的裸调用；函数体内的子函数调用及别名继续按其局部作用域处理。
