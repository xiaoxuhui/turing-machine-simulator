# 符号等分配色：需求与测试用例

日期：2026-10-31。用户要求按所有不同写入字符的数量等分颜色渐变，并最终明确：普通字符不用红色，红色仅给读写头。采用黄→绿→蓝→黄，不随机或散列。

- U01：按规则写入符号首次出现顺序去重，排除空白；以唯一符号数量 N，在三段循环渐变上取 N 个等距采样点。
- U02：未执行到的写入符号也计入配色。输入中独有的非空符号追加到末尾，保证其也能显示。
- U03：读写头仍以粉红混入当前符号色30%，图例与画布一致，注明符号总数。
- U04：改变运行步数不改变同一机器与输入的颜色；不修改计算与采样。
- U05：单测覆盖1、4、8种符号、去重和空白；真实浏览器覆盖8种写入字符（含未执行分支）、等分色、头色及步数变化稳定性。

- U06：头读到空白时保留红色，普通空白背景保持浅色。用户提及“零”后已澄清是“红”的误解，不增加空白配色名额。
