# 符号等分配色：设计文档

createRoutePalette 接收有序符号集合，保序去重去空白。三个锚点为黄 #eab308、绿 #22c55e、蓝 #3b82f6，再回到黄。索引 i 的位置为 3*i/N，在相邻锚点间线性插值得到颜色；N=3 为三个锚点，N=8 为八个等距色，普通符号没有红色。

发起生成时从机器规则 writeSymbol 和初始输入收集符号，捕获本次任务的调色板；绘制时使用该板而非从采样帧反推。后台运行中用户切换程序不影响旧任务配色。headColor 接收已分配色进行混合，保留粉红基色70%；头读到空白时为原粉红，空白背景仍浅色。移除旧按字符串散列的颜色计算。
