## 架构变化

```text
main.ts（装配与 UI 协调）
├─ execution-scheduler.ts（时间片、批量、实际速度）
├─ route-controller.ts（Worker 生命周期）
├─ route-worker.ts（后台机器执行与采样）
└─ route-bounds.ts（安全边界扫描）
```

控制器通过回调与页面连接，核心调度与 Worker 生命周期无需 DOM 即可测试。
