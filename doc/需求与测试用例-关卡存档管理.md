# 关卡存档管理需求与测试用例

## 目标

玩家可以把当前关卡完成状态和规则草稿保存成 JSON 文件，日后从文件恢复；也可以确认后一次清空全部关卡进度与草稿。

## 规则

- 浏览器继续自动保存；“保存备份”额外下载一个可携带的 JSON 文件。
- 备份包含当前已通关关卡 ID 和各关已保存规则草稿。旧存档中从未记录的规则无法反推。
- 导入前校验文件类型、版本、关卡 ID 和草稿结构；无效文件不得覆盖当前进度。
- 导入有效备份会替换当前进度和草稿，先显示确认框。
- “一键清空”经确认后删除当前设备的关卡存档，不影响下载过的备份文件。
- 单个备份文件最多 1 MiB；所有操作只涉及关卡存档，不修改自由实验台数据。

## 验收

- U01：序列化再解析后，完成状态和各关草稿原样保留。
- U02：错误版本、未知关卡、非法草稿和过大文件被拒绝，当前数据不变。
- U03：清空后进度为 0/16，草稿回到关卡初始提示；刷新后仍为空。
- U04：导入备份后页面和本地存储同步，刷新后仍保留导入内容。
- U05：取消导入或清空确认，不修改已有进度。
