# 图灵机模拟器需求文档

> 状态：待确认  
> 版本：0.1  
> 日期：2026-08-19

## 1. 项目目标

制作一个可在 Google Chrome 中直接使用的可视化、可编程单纸带确定性图灵机模拟器。用户无需安装开发环境，即可编辑转移规则、设置输入、单步或连续执行程序，并观察纸带、读写头、状态与执行记录的变化。

首版以“概念准确、操作直观、便于教学和实验”为核心，不追求在图灵机内部模拟现代计算机，也不涉及康威生命游戏。

## 2. 目标用户

- 初次学习图灵机、自动机或可计算性理论的学生。
- 希望通过逐步执行理解状态转移的自学者。
- 需要快速编写和验证小型图灵机程序的教师或开发者。

## 3. 首版范围

### 3.1 机器模型

- 单纸带、单读写头、确定性图灵机。
- 纸带向左、向右按需扩展。
- 每个纸带单元保存一个符号。
- 支持左移 `L`、右移 `R`、原地不动 `N`。
- 用户可配置状态集合、输入字母表、纸带字母表、空白符、初始状态和停机状态。
- 同一“当前状态 + 当前符号”最多只能有一条规则。
- 找不到适用规则时停止运行，并明确显示“缺少转移规则”，不自动判定为接受。

### 3.2 纸带视图

- 水平显示连续纸带单元、符号和逻辑位置编号。
- 明确标出当前读写头和当前状态。
- 读写头移动时，视图自动跟随。
- 支持拖动或按钮浏览读写头附近之外的纸带区域。
- 支持点击纸带单元并修改符号；运行时禁止误编辑。
- 提供“回到读写头”操作。

### 3.3 程序编辑

- 以结构化表格编辑转移规则。
- 每条规则包含：当前状态、读取符号、下一状态、写入符号、移动方向。
- 支持新增、修改、删除和复制规则。
- 实时检查重复规则、空字段、非法方向以及不属于字母表的符号。
- 错误规则必须醒目标记，并阻止连续运行。
- 支持用纯文本批量编辑或粘贴规则，格式为：

  ```text
  q0,1 -> q0,1,R
  q0,□ -> HALT,1,N
  ```

- 结构化表格与纯文本表示可相互转换。

### 3.4 输入与初始化

- 用户可输入初始纸带内容。
- 默认从输入内容最左侧非空单元开始；允许用户指定初始读写头位置。
- 修改程序或输入后，可执行“重置”，恢复到本次运行的初始配置。
- 提供“清空项目”，并在执行前避免误操作造成数据丢失。

### 3.5 运行控制

- 单步：精确执行一条转移规则。
- 运行：按照设定速度连续执行。
- 暂停：保留当前配置，随后可继续。
- 重置：回到初始配置，步数归零。
- 支持运行速度调节。
- 设置单次连续运行的最大步数，默认 10,000 步，可由用户调整。
- 达到最大步数时自动暂停，而不是判定停机。
- 页面切换到后台时仍应避免失控占用资源。

### 3.6 状态与反馈

- 始终显示当前状态、当前符号、读写头位置、累计步数和运行状态。
- 运行状态至少包括：就绪、运行中、已暂停、已停机、规则错误、达到步数限制。
- 每次单步后高亮刚执行的规则。
- 停机后说明停机原因；若进入用户指定的接受或拒绝状态，分别显示结果。

### 3.7 执行记录

- 记录每一步的步号、原状态、读取符号、写入符号、移动方向、目标状态和读写头位置。
- 支持查看最近若干步，避免无限增长拖慢页面。
- 支持清空记录。
- 首版提供导出执行记录为文本或 CSV 的能力。

### 3.8 示例程序

首版至少内置以下可直接运行的示例：

1. 一进制加一。
2. 二进制加一。
3. 二进制反转或复制中的一个。
4. 回文判断器。
5. 2 状态忙碌海狸。

每个示例包含简介、推荐输入和预期结果。加载示例会替换当前编辑内容，因此需要防误覆盖提示。

### 3.9 保存与导入导出

- 自动保存最近一次项目到浏览器本地存储。
- 重新打开页面时可恢复上次内容。
- 支持导出完整项目为 JSON。
- 支持导入本工具导出的 JSON，并进行严格格式校验。
- 导入失败不得破坏当前项目。
- JSON 中至少包含格式版本、机器配置、规则、初始纸带和初始读写头位置。

### 3.10 基础易用性

- 支持桌面 Chrome，首版优先适配宽度 1280 像素及以上。
- 关键操作支持键盘：空格运行/暂停、方向键或指定快捷键单步、`Esc` 停止编辑或关闭弹层。
- 不只依赖颜色传达运行和错误状态。
- 输入框、按钮和规则表具备清晰标签与焦点状态。
- 中文为首版界面语言；机器状态和符号允许使用英文、数字及常见 Unicode 字符。

## 4. 页面结构

首版采用单页面工作台：

1. 顶部工具栏：项目名、示例、导入、导出、帮助。
2. 运行状态区：当前状态、读写符号、头位置、步数、速度。
3. 纸带主视图：纸带、位置编号、读写头和状态标记。
4. 运行控制区：单步、运行/暂停、重置、回到读写头。
5. 配置与规则区：机器配置、初始输入、转移规则编辑器。
6. 执行记录区：最近步骤和停机原因。

## 5. 非功能需求

- 完全本地运行；首版不需要服务器、账户或网络连接。
- 不采集、不上传用户输入和程序数据。
- 典型小型机器单步操作应即时响应。
- 连续运行不得使界面长期失去响应。
- 核心执行引擎与界面分离，便于自动化测试。
- 同一初始配置与规则必须产生可重复的执行结果。
- 项目文件需可在 Windows 上直接打开或通过简单本地服务运行。

## 6. 首版不包含

- 多纸带、多读写头、非确定性或概率图灵机。
- 通用图灵机编码器或在一台图灵机中解释另一台机器的完整编码。
- 康威生命游戏或其他元胞自动机。
- 在线协作、云端同步、账号系统和远程代码执行。
- 图形化状态节点连线编辑器；可作为后续版本候选。
- 移动端完整编辑体验。

## 7. 验收标准

### 7.1 核心正确性

- 给定规则 `(q0, 1) -> (q1, 0, R)`，单步后必须写入 `0`、右移一格并进入 `q1`。
- 纸带跨越当前可视边界时，数据不能丢失，读写头可以继续移动。
- 重置后，纸带、状态、头位置和步数与初始配置一致。
- 重复规则和非法符号不能进入运行状态。
- 缺少规则、进入停机状态和达到步数上限必须得到不同反馈。

### 7.2 数据可靠性

- 页面刷新后能恢复最近保存的有效项目。
- 项目导出后重新导入，机器配置与行为保持一致。
- 无效 JSON 导入失败时，导入前项目保持不变。

### 7.3 示例验证

- 一进制加一示例输入 `111` 后停机并得到 `1111`。
- 二进制加一示例至少通过 `0→1`、`1→10`、`1011→1100` 三组测试。
- 回文判断器至少正确区分一组接受输入和一组拒绝输入。
- 忙碌海狸示例产生预先记录的确定结果与步数。

## 8. 待确认事项

1. 首版是否确定为单纸带确定性图灵机。
2. 是否接受“结构化规则表 + 纯文本批量编辑”两种编辑方式同时提供。
3. 首版是否保留回文判断器和忙碌海狸示例。
4. 是否需要在首版加入撤销/重做。
5. 是否采用“中文界面、状态与符号自由输入”的语言策略。
