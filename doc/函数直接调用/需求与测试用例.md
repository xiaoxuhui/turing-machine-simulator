# 函数直接调用：需求与测试用例

日期：2026-10-30。用户要求：状态跳到函数时可省略写入和移动，直接调用。

- U01：`q0,1->f` 等价于 `q0,1->f,1,N`，保留读取条件，不改纸带、不移动读写头。
- U02：支持顶层、函数体、子函数别名、后置函数定义，沿用已有续行、后续同名调用查找和 ret。
- U03：简写目标必须为该作用域可见的已定义函数；普通状态、拼错的函数、终态不能误当作简写调用。显示原行号。
- U04：完整规则的写入、移动仍然生效；简写与完整形式编译结果一致，条件不匹配仍缺规则。
- U05：真实浏览器检查编辑、应用、单步和实际规则输出，用户草稿不被测试覆盖。
