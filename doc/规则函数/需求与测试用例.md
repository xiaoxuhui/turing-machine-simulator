# 缩进规则函数需求与测试用例

日期：2026-10-27；用户指定 `函数名(初始状态):` 定义、空格缩进划定函数体，调用只写函数名，不写 def、调用参数或 return。

- F01：函数体支持原有转移规则，中文函数名可用，定义不自动执行；顶格写函数名按顺序调用，可先调用后定义。
- F02：定义中的初始状态必须在函数规则中出现。不同函数可以使用相同的局部状态名，多次调用不冲突。
- F03：函数内转移进入配置的普通停机态（默认 HALT）即结束本次调用，自动续接下一个调用，最后一次正常停机；接受/拒绝仍终止全程序。缺失规则不是返回，照常报告缺失。
- F04：支持以函数名作为普通转移规则的目标状态（尾调用），或将初始状态框填为函数名；无函数的旧规则全部兼容。顶格调用列表不与顶格普通转移规则混写。
- F05：函数体也可由一串缩进函数名组成，作为顺序组合函数；与转移规则不能混写。拒绝递归、未定义调用、重复定义、非法缩进、空函数及过大展开，并保留源码行号。
- F06：函数只编译成普通有限转移规则，不通过 JavaScript 运算代替图灵机。源码随原项目格式导入/导出和保存，执行入口由编译结果确定。
- F07：结构化表展示展开结果且只读，避免编辑副本破坏函数源；文本中可正常编辑和插入缩进。提供完整可运行示例和说明，旧示例及关卡回归通过。
- F08：验证顺序调用、复用、中文、嵌套组合、尾调用、局部作用域、定义顺序、异常行号、导入导出和表格只读；真实浏览器完成完整算例。
- F09：用户编辑后立即独立保存原始草稿，不要求先应用；刷新保留缩进、空文本和未完成/有语法错误的函数，不回退旧规则。主动加载示例或导入时替换旧草稿；保存失败明确提示，不能声称已保存。
