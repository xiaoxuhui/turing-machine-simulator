# 缩进规则函数设计

日期：2026-10-27。

新增 `rule-functions.ts`，保留原扁平规则快速路径，通过 `parseTransitions` 统一提供解析入口。语法由顶格函数头、同宽空格缩进的函数体、顶格调用或普通规则组成。函数体分为规则函数和组合函数，禁止混合及递归；转移到函数名按尾调用处理。静态展开为命名空间隔离的状态副本，显式退出态（或单参数旧定义的普通停机态）映射到续接入口，最后一次映射到全局普通停机态；接受/拒绝终态不改。核心依旧只执行原有转移。

解析结果追加可选的顺序调用入口、函数入口映射和函数标记。实验台、项目校验及关卡校验统一传入终态配置、解析初始状态，避免导入或试跑使用错误入口。旧格式不增加字段，源码仍是 rules 文本。函数表格展示编译后的转移并禁用编辑和新增，原扁平表格编辑不变；文本框 Tab 插入四空格。

编译前检查调用图；限定展开深度 64、实例 10000、函数展开规则 100000，超限返回明确错误而非卡住。用户源码中的终态和函数名不得与局部状态定义冲突。生成命名空间选择不与源码状态前缀冲突的名称。纯扁平大规则表不受新增函数展开限制。

原始编辑草稿使用独立 localStorage 键，不走合法项目校验；保存机器字段的原始字符串（含空文本及非法语法），不改最后有效项目及速度偏好。每次输入先同步保存再识别规则；启动优先合并草稿后再尝试创建机器，语法错误只提示、不丢弃文本。主动填充示例/导入项目时同步替换草稿。持久化异常显示刷新可能丢失的警告。

补充退出参数：函数头允许第二个状态名作为局部退出态。编译时该目标映射为调用的续接入口；其它全局终态仍保留原停机/接受/拒绝含义。单参数旧定义继续使用普通停机态作局部结束点。初始态不能等于退出态；退出态不能与函数名、接受态或拒绝态冲突，也不能定义出边，防止不明确的控制流。
