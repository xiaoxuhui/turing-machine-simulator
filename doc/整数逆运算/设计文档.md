# 整数逆运算：设计文档

复用现有Program生成器的inc/dec/copy/move/clear，新增InverseProgram。输入R0为次数/底数，R1为阈值，R2为最终答案。候选值逐次加一，计算对应正向Hk；成功则把候选复制为答案，超过阈值直接清理停机。

正向试算使用带预算乘法：每次给乘积加一，同时把预算（从R1复制）减一；预算耗尽时仍要加一则说明超过阈值，直接转到保留上次答案的完成分支。高阶运算递归展开到这种乘法；参与试算的底数均≥1，超限可安全提前退出。

register-tm增加~、~~、~~~、@、@@、@@@输入分隔符，验证字母表加入~和@；不改现有算术的规则规模或运行语义。六个项目作为独立一进制示例接入，不把新操作混入旧正向示例集合的固定测试。

根号次数0、高阶根号阈值0、对数底数0/1、对数阈值0拒绝。普通根号x=0在验证次数正后直接返回0。根号试候选底数，对数试候选次数；指数/高度0对应1，作为对数答案0的起点。
