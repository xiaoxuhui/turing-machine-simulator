# 整数逆运算：需求与测试用例

日期：2026-11-01。用户要求加入n次方根、对数、超根号、超对数、超超根号、超超对数，并确认使用整数逆运算、向下取整。

用H3(a,b)=a^b、H4(a,b)=a↑↑b、H5(a,b)=a↑↑↑b，沿用现有正向递推和Hk(a,0)=1。

- U01：根号输入n~x，返回最大整数a≥0使a^n≤x，n≥1、x≥0。
- U02：超根号n~~x、超超根号n~~~x，返回最大整数a≥1使H4/5(a,n)≤x，n≥1、x≥1。
- U03：对数a@x、超对数a@@x、超超对数a@@@x，返回最大整数b≥0使H3/4/5(a,b)≤x，a≥2、x≥1。
- U04：上述均为整数阈值逆运算，不计算非整数高度的解析延拓。边界等号接受，超过阈值才停止试探；非法域进入REJECT。
- U05：所有数值仍由普通单纸带图灵机转移计算；转换时只生成有限规则。正向试算超过x时立即结束该候选，避免展开远大于输入的结果。
- U06：六个示例均有分段原理注释和纯规则版，说明输入、域和输出。实际浏览器加载和运行，旧示例保持。
