# 设计文档：纸带视角「随意拖动」模式

## 设计
- **D1** 扩展 `TapeViewMode` 联合类型，新增 `"free-drag"`。
- **D2** `tapeWindowCenter(mode, head)`：`follow-head`→`head`，`fixed-zero`→`0`，`free-drag`→`0`（基准都在零，满足“初始位置在零”）。
- **D3** 新增纯函数 `effectiveTapeScroll(mode, scroll)`：仅 `free-drag` 返回 `scroll`，否则返回 `0`。
  渲染中心改为 `center = tapeWindowCenter(mode, head) + effectiveTapeScroll(mode, tapeScroll)`。
- **D4** `setScroll` 回调门控：仅当当前视角为 `free-drag` 才写入 `tapeScroll` 并重渲染；其余模式忽略。
  由此**删除**原“所有视角下均可拖动”的行为。
- **D5** 视角 `change` 事件：先 `tapeScroll = 0` 再 `render()`，防止跨模式串扰。
- **D6** 光标：纸带元素加 `can-drag` 类（仅 `free-drag` 时由 `renderTape` 切换）。CSS 仅在该类下显示 `grab/grabbing`；
  移除原先 `.tape` 默认 `grab`，让其它模式纸带光标恢复正常。
- **D7** 复用现有 `attachTapeDrag`、`panFromDragDelta`、`isHeadInWindow`（窗外头部指示保留，对 `free-drag` 探索有用）。

## 删除项（原跨模式拖动）
- 原实现：`center = tapeWindowCenter(mode, head) + tapeScroll`，`tapeScroll` 在任何模式下拖动都生效。
- 新实现：非 `free-drag` 时 `effectiveTapeScroll` 返回 0，且 `setScroll` 忽略，等于删除该行为。

## 数据流
```
视角切换 → tapeScroll=0 → render
拖动(pointer) → setScroll(仅 free-drag 写入) → tapeScroll → renderTape → center = base + effectiveTapeScroll
```
