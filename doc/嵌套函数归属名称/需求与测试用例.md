# 嵌套函数归属名称

日期：2026-11-05。状态：PENDING。

用户要求 COPY 内调用 FUCC 时名称明确体现 COPY.FUCC 等所属关系，实际名称、运行、规则表都一致，并加入示例。

- U01：子函数实际状态包含完整调用路径，例如 __fn.3.COPY.FUCC.q0，编号区分不同实例。
- U02：COPY 和 OTHER 调用同一 FUCC 时不能因续接相同而共用不含归属的状态；多层嵌套显示完整路径，顶层 FUCC 入口仍独立。
- U03：组合函数、普通函数、混合调用与别名都保留归属；名称映射的来源也包含所属路径。
- U04：外部状态保留原名，ret/导出/普通续行行为不变；父函数任意状态规则不能捕获子函数状态。
- U05：新增函数教程可运行示例，有注释/无注释、数字/原名、展开/函数版本等价，真实浏览器核对运行状态和实际规则。
