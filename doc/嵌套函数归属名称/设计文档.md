# 嵌套函数归属名称设计

日期：2026-11-05。状态：VERIFIED。

每个编译 Context 保存实例编号、调用路径和父实例编号；scope 使用全局唯一实例前缀加完整调用路径。示例：父 __fn.2.COPY.q0，子 __fn.3.COPY.FUCC.q0。实例编号放在路径前，确保父范围 __fn.2.COPY.* 不会误匹配子函数。

缓存键加入父实例身份和实际调用源行，避免不同父函数、不同父实例，以及同一父函数内不同位置的调用在续接和 ret 相同时共享一个子上下文。组合函数即使没有自己的普通状态也保留 Context 路径和编号。公共导出默认入口只选没有调用位置的独立根上下文，不能误取同一函数的嵌套实例或顶格调用实例。

内部映射使用完整路径，实际运行仍使用编译后的相同名称；外部普通状态与绑定状态保持原名。新增 COPY、OTHER 调用 FUCC 的教程展示同一个函数定义在不同调用位置的归属。

同一源码行在多个实例中产生完全相同的全局状态转移时，只保留该条相同转移；源码位置不同、目标/读写/方向不同仍按重复规则报错，不能覆盖冲突。实际教程使用 COPY 在两个位置调用 SUCC，再由 OTHER 调用一次。斐波那契旧函数转换可能因独立实例而增加编译规则条数，原始 54 条源码及逐步纸带等价性必须保持，不能再把函数版条数固定为 54。
