# 星号默认值

日期：2026-11-04。状态：COMPLETE。

用户要求空白位置使用星号，函数同样适用。写入字段 `*` 保持读取符号；移动字段 `*` 不移动。原有留空、简写、完整写法兼容。字段按逗号位置解释，不将写入的 R/L 当方向。

- U01：`q,1->end,*,R` 保持 1 并右移；`q,1->end,L,*` 写 L、不移动。
- U02：`q,C1->end,*,*` 保持多字符符号、不移动；星号周围可有空格。
- U03：读取字段 `*` 仍是字面星号，不是通配符；乘法原有星号分隔符保持正确。
- U04：函数体、函数目标、普通状态、终态均使用相同默认值，展开与完整规则等价。
- U05：规则表支持星号写入、星号移动，实际运行与展开结果相符；旧留空语法继续正确。
- U06：非法方向仍定位错误；所有示例回归通过。
