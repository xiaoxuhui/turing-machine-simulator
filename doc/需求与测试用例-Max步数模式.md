# Max 步数模式需求与测试用例

状态：已确认。2026-10-12 用户希望实验台能选择 Max，而不受固定最大步数限制。

## 需求

- 实验台最大步数旁增加 Max 开关；启用时不因步数阈值暂停，仍可手动暂停或因机器停机而停止。
- 关闭 Max 后恢复可编辑的有限步数，默认 10,000，范围仍为 1–1,000,000。
- 本地自动保存及项目 JSON 导入导出要保留 Max 模式；旧项目继续按有限步数读取。
- 关卡验证和全路线总览不受该开关影响。

## 验收

- U01：项目格式接受 `maxSteps: null` 表示 Max，并保持旧数字格式兼容。
- U02：Max 模式下超过原有限步数仍能运行，手动暂停有效。
- U03：切回有限模式后阈值重新生效。
- U04：刷新及 JSON 导入导出后 Max 状态保留。
