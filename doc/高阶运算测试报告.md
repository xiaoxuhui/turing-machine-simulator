新增测试使用现有 `TuringMachine` 逐步执行，不使用寄存器解释器替代图灵机：

- 编译器：0–5 两操作数的全部 36 组搬运加法；非法跳转在编译前拒绝。
- 除法：分子 0–8、分母 0–4 的全部 45 组输入；分母为 0 进入 REJECT，其余取整商。
- 乘方：底数与指数各 0–3 的 16 组；覆盖底数 0、指数 0、约定 `0^0=1`。
- 超幂：底数 1 高度 0–5；底数 2 高度 0–3；`3↑↑1=3`、`3↑↑2=27`；底数 0 拒绝。
- 超超幂：底数 1 次数 0–4；底数 2 次数 0–2；`3↑↑↑1=3`；底数 0 拒绝。
- 11 组格式错误：遗漏分隔符、符号位数不对、重复分隔符、使用数字 0 等。
- 四个默认输入；检查停机态、输出精确且连续、无工作区符号残留。共 99 次高阶示例机器运行（含上述错误和默认输入）。

## 约定与未验收范围

幂塔采用右结合，参考 [Knuth 上箭头记号](https://mathworld.wolfram.com/KnuthUp-ArrowNotation.html)。超幂、超超幂要求正整数底数；高度/次数 0 为 1。普通乘方在本项目中约定 `0^0=1`，并非宣称所有数学语境统一如此。

默认值刻意保持小规模。没有运行到 `2↑↑4` 或 `2↑↑↑3` 的最终停机；这两者有 65,536 个输出单元，一进制搬运所需转移远超输出长度。Max 只移除固定步数上限，不承诺任意大输入可在可接受时间内算完。未重新测试安卓 APK，也未打新版本标签。
