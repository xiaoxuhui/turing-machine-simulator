# 图灵机实验台 v0.3.0

首个公开版本 🎉

一个可视化、可编程的单纸带确定性图灵机模拟器。本项目是一个面向小朋友的娱乐项目，issue 响应不保证时效，欢迎 fork 自行改造。

## ✨ 特性

- **纸带自由拖动**：新增「随意拖动」视角，可整体左右拖，突破固定 ±8 范围
- **平滑跟随读写头**：跟随视角改为平滑过渡，不再逐格跳变
- **随速度自适应的滑动时长**：速度 1 慢走、速度 10 快走，不再先停一会再猛跳
- **目标速度双输入**：滑杆 + 数字输入框，双向同步（1–1000）
- **全路线总览**：红 = 读写头位置，绿 = 非空纸带格
- **计算瓷砖拼图**：把运行轨迹拼成可玩的瓷砖
- 内置多套示例机器（二进制计数、加法、回文检测等）
