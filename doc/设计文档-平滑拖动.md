# 设计文档：平滑拖动

## 现状问题
`tape-drag.ts` 的 `pointermove` 处理器直接 `setScroll(panFromDragDelta(startScroll, deltaX, pitch))`，
而 `panFromDragDelta = startScroll - Math.round(deltaX / pitch)`，因此每帧都取整到整格 → 视觉跳变。

## 设计
引入「整数格基 + 亚格余数」两段式：

1. **整数格基**：`setScroll(panFromDragDelta(...))` 仍负责整格平移，触发 `renderTape` 重渲染，
   保证窗口中心、读写头边缘指示、纸带范围都基于正确的整数位置。仅在**跨越格边界**时变化。
2. **亚格余数**：`remainder = deltaX - Math.round(deltaX / pitch) * pitch`，
   通过新增回调 `applyShift(px)` 把余数作为 CSS `transform: translateX(px)` 施加到 `#tape` 上，
   让纸带在两格之间像素级连续跟随。
3. **松手吸附**：`pointerup` / `pointercancel` 时调用 `applyShift(0)` 清除 transform，
   纸带停在最后一次 `setScroll` 提交的整格位置。

### 模块接口变更
`TapeDragOptions` 新增：
- `applyShift(px: number): void` —— 宿主施加/清除亚格 transform。
- `isEnabled(): boolean` —— 仅「随意拖动」模式返回 true；false 时 `pointerdown` 直接 return，不启动拖动。

### 宿主接线（main.ts）
- `setScroll`：保留 free-drag 门控；并 `if (newValue === tapeScroll) return;` 避免亚格移动时重复重渲染（性能/减少闪烁）。
- 新增 `applyShift`：`byId("tape").style.transform = px === 0 ? "" : \`translateX(${px}px)\``。
- 新增 `isEnabled`：`() => value("tapeViewMode") === "free-drag"`。
- 视角切换 `change` 事件：额外 `byId("tape").style.transform = ""` 清除可能的残留 transform。

### 样式
`.tape.can-drag`（及 `.tape.dragging`）加 `will-change: transform;` 提示浏览器做合成层优化，滚动更顺。

## 影响面
- 仅影响 free-drag 模式下的拖动手感；不动视角类型、不动其它模式、不动核心算法。
- `panFromDragDelta` / `effectiveTapeScroll` / `isHeadInWindow` 均复用，无需改动。
