# 父函数在前的名称设计

日期：2026-11-05。状态：COMPLETE。

保留实例缓存的父身份和调用位置，只调整实际 scope 格式。根函数 scope 为 name.FN.id.；子函数为 parent.path.FN.id.name.。例如 COPY.FN.5.SUCC.q0，更多祖先保留在 parent.path 中。编号仍全局唯一，父范围 COPY.FN.3.* 不会匹配子范围 COPY.FN.5.SUCC.*。

从用户状态、终态、函数名、公开状态中检查 .FN. 标记；若已存在则选择 FN_，继续递增下划线直到无碰撞。顶层脚本合成名仍使用既有避碰前缀，其含义不属于函数状态编号。实际名产生点统一改变，运行器不增加别名表或显示替换。
