# 全局示例版本：设计文档

新增example-variants.ts。保留原结构时只改状态字段：预扫描函数头及别名，函数名称不编号，局部/外部同名字面状态使用相同映射，公开引用保留函数前缀并改局部状态；终态保留原名，避免破坏停机配置。

无函数版复用parseTransitions和resolveInitialState展开。有函数版按规则块提取公共函数：一个入口状态的规则至少两条、内部只有自循环和一个外部出口，将读取/写入/移动相同但状态名和出口不同的块归为一组。每组至少两个调用点，函数体仅定义一次，各调用点写“入口状态: 公共函数 -> 续接状态”，无额外控制转移。原有手写函数保持原结构；无重复块时保留原规则，明确说明。

编译器新增顶层带入口名及续接地址的函数调用声明，将入口名直接解析到函数实例入口，正常完成跳至指定状态；每个调用点可有独立续接地址。数字重命名也处理这类入口/续接状态。该语法使公共扫描规则真正复用，而不依赖调用位置的下一行布局。

斐波那契使用已有专用版本生成器保留原数字状态及四阶段分组，但控制入口改为全局选项。所有选择均只预览；注释继续交由exampleSource处理。
