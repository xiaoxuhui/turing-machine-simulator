# 安卓打包需求与测试用例

> 将「图灵机实验台」网页应用打包为可安装的安卓 APK（WebView 外壳 + 内置资源，全离线）。
> 依据技能 `web-app-to-android-apk` 的验收要点，结合本项目实际网页能力（localStorage / 导入 / 导出）定制。

## 项目参数（默认，未另行指定）

| 参数 | 取值 |
|---|---|
| 包名 / applicationId | `com.xiaoxuhui.turing` |
| 显示名 | 图灵机实验台 |
| minSdk / targetSdk | 24 / 34 |
| 版本 | versionName `0.3.1`，versionCode `1` |
| 网页形态 | C 类（Vite 产物），构建用相对 `base: ./` |

## 网页能力 → 外壳处理映射

| 网页能力 | 出处 | 外壳处理 |
|---|---|---|
| `localStorage` 持久化项目 | `main.ts:185,635` | `domStorageEnabled=true` + 固定域名加载，origin 稳定 |
| `<input type="file">` 导入 JSON | `main.ts:45,564` | `WebChromeClient.onShowFileChooser` |
| `Blob` + `<a download>` 导出 | `main.ts:509-513,563,579` | 注入脚本劫持 click → JS 桥 `TuringAndroid.saveFile` 写系统下载目录 |
| ES module / fetch 加载资源 | Vite 产物 | `WebViewAssetLoader` 的 https 域，非 `file://` |

## 验收用例

### 安装与启动
- **U01** 在安卓 7.0+（含鸿蒙 4.x AOSP）可正常安装 debug APK。
- **U02** 启动无崩溃，首屏显示「图灵机实验台」界面（非白屏）。
- **U03** APK 内 assets 的网页与 `dist/` 构建产物字节一致（CI 通过 `cmp` 校验）。
- **U04** 断网可完整使用（外壳不请求任何网络，无 INTERNET 权限）。

### 核心功能与网页端一致
- **U05** 单步 / 运行 / 暂停 / 重置 行为一致；运行中实时速度显示更新。
- **U06** 视角「随意拖动」可整体左右拖动，突破 ±8 范围；拖远有「读写头在 N」提示。
- **U07** 视角「跟随读写头」运行时平滑滑动而非逐格跳。
- **U08** 目标速度滑杆与数字框双向同步；越界值被夹到 1–1000。
- **U09** 示例程序（binary / palindrome 等）切换后正确加载、纸带重置。

### 数据持久化
- **U10** 修改项目后杀进程重进，配置仍在（localStorage）。
- **U11** 旋转屏幕（横/竖）不丢状态、不重建 Activity。

### 导入导出
- **U12** 导出项目 JSON / 日志 CSV：点击后在系统下载目录落盘，并 Toast 提示保存路径。
- **U13** 导入 JSON：调起系统文件选择器，选中后正确载入。

### 适配
- **U14** 手机竖屏不被状态栏/挖孔遮挡（edge-to-edge padding）。
- **U15** 平板横屏布局可用，不锁方向。
- **U16** 双指缩放被禁用，页面按 100% 显示。

### 导航
- **U17** 返回键优先回退网页历史，历史为空才退出应用。

### 图标与元数据
- **U18** 各密度传统图标 + 自适应图标前景齐全，启动图标显示正常。
- **U19** 应用名称显示为「图灵机实验台」。

### 构建与发布
- **U20** CI 成功产出 debug APK 并作为 artifact 上传；打 tag 后挂到 GitHub Release。
