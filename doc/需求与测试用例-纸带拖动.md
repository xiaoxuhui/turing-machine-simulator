# 需求与测试用例 — 纸带可鼠标左右拖动（feature: draggable-tape）

- **文档版本**：v0.4.0-feature
- **状态**：草稿（待实现）
- **实施策略**：在现有「图灵机实验台」纸带区域上新增鼠标拖动平移能力，不改动现有机器逻辑与视角模式语义。
- **关联规范**：`plan-driven-frontend-dev`（规划先行 + 每功能一 commit + 测试驱动 + 文档齐全）。

## 1. 背景

用户希望在图灵机实验台**上方那条纸带**（`.tape` / `#tape`）上，用鼠标**左右拖动**来平移查看不同纸带位置。
纸带初始停在**位置 0**（机器未运行时读写头在 0，窗口以 0 为中心），之后用户可随意左右拖动查看更左或更右的位置。

> 术语对齐：用户口语中的「下一个模式」经确认即指页面上方的**纸带显示区**。

## 2. 产品需求（分模块）

### R1 纸带可拖动平移
- 在 `#tape` 区域内按住鼠标并左右拖动，纸带可视窗口随之左右平移，显示不同的纸带位置。
- 拖动方向约定：鼠标向右拖 → 纸带内容向右移 → 显示更小（更负）的位置；向左拖反之。

### R2 初始位置为 0
- 页面初始（机器未运行、读写头在 0）时，纸带以位置 0 为中心；`tapeScroll` 初始值为 0（未平移）。

### R3 与现有视角模式兼容
- 拖动偏移叠加在现有视角模式基准中心之上：`center = tapeWindowCenter(mode, head) + tapeScroll`。
- `follow-head`：基准 = 读写头位置；`fixed-zero`：基准 = 0。拖动在两种模式下均生效。

### R4 重置归位
- 点击「应用并重置」或「重置」时，`tapeScroll` 归零，纸带回到当前模式的基准中心。

### R5 视觉与交互反馈
- 拖动过程中鼠标光标为 `grabbing`，且不发生误选中文本（`user-select: none`）。
- 空闲时 `#tape` 光标为 `grab`，提示可拖动。

## 3. 验收用例

- **U01（拖动平移）**：在 `#tape` 上 `pointerdown`(clientX=500) → `pointermove`(clientX=450，约拖动 8 格) → `pointerup`，断言 `tapeScroll` 由 0 变为约 +1（向左拖，显示更大位置）；再次向右拖使 `tapeScroll` 变负。
- **U02（初始为 0）**：加载页面、未拖动时，纸带中间格标注的位置为 0（机器未运行时）。
- **U03（叠加基准）**：在 `fixed-zero` 模式下 `tapeScroll=+2` 时，中心位置应为 `0 + 2`；`follow-head` 且 head=3 时中心为 `3 + 2`。
- **U04（重置归位）**：拖动后点击「重置」，断言 `tapeScroll` 回到 0，中心回到基准。
- **U05（像素→格子换算）**：`panFromDragDelta(0, +57, 57)` 应返回 `-1`；`panFromDragDelta(0, -57, 57)` 返回 `+1`；`panFromDragDelta(2, +28, 57)` 返回 `2 - round(28/57)=2-1=1`。
