# 函数类型参数

日期：2026-11-05。状态：COMPLETE。

以用户最后澄清为准：第一个位置是初始状态，第二个位置是退出状态，后面才是参数，不在前两个位置之间插入类型。

定义示例：`示例(q0,done,动作=右移,函数,出口=q1,状态,1,符号):`。仍使用裸函数名调用；绑定在定义时指定。函数或外部状态使用内部名=目标；符号直接填写。旧写法兼容，未标类型的等号绑定先判断函数，否则按外部状态。

- U01：入口/退出仍占前两项，旧函数、别名、ret、导出、续行全部兼容。
- U02：函数类型参数可转移调用、裸调用和绑定别名；错误函数名带源行号。
- U03：状态类型参数从内部跳到真正外部状态，名称表、展开表、真实机器一致，不能加函数内部前缀。
- U04：未标类型的等号绑定先识别函数，再作为外部状态；符号类型直接填写，支持多字符符号，不要求内部符号=实际符号。
- U05：类型不匹配、重复别名、与入口/退出冲突、把状态当裸函数调用等错误明确定位；不执行错误程序。
- U06：示例与帮助说明正确语法，有注释、无注释、数字状态、展开、公共函数版本等价。
- U07：真实 Chromium 加载、实际执行、展开映射及外部状态不带前缀得到核对。
