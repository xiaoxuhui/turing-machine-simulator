# 函数类型参数设计

日期：2026-11-05。状态：COMPLETE。

在 header 参数层解析可选的“值,类型”配对，前两项保留原初始/退出语义。类型为函数、状态、符号（可接受英文同义词）；符号直接记录为本函数使用的符号，按原规则读取和写入，不进行字符串替换。函数/状态内部别名在各自位置解析，保持符号与状态命名空间分离。

类型解析独立成模块；函数绑定留给原调用编译路径，状态绑定新增明确的外部状态解析，不能通过重命名全局状态的显示掩盖真实运行。来源和目标位置都使用同一个实际外部状态；合并后规则冲突沿用原有重复规则诊断，不能覆盖全局表。入口/退出不能被参数重绑定。未标注类型的等号绑定支持先查函数，否则为状态。未带等号的旧子函数列表仍要求函数存在。

所有函数仍编译成普通图灵机规则；没有运行时求值器。外部出口保留外部声明/表达式的实际入口，未知外部状态保持原名，到达时按现有机制报告缺少规则。ret、正常结束及局部隔离保持原语义。

示例状态数字化识别类型，函数别名和符号不数字化，外部状态绑定目标随全局状态一起数字化。帮助与新示例说明参数顺序。
