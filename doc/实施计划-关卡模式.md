# 图灵机实验台：关卡模式实施计划

## 目标

在不破坏自由实验模式的前提下，把关卡改为独立页面，交付 8 关带逐步教程、可编程、可验证、顺序解锁并本地保存草稿与进度的教学模式。

## 执行原则

- 先纯领域模型与测试，后页面集成。
- 每个逻辑功能独立提交，每阶段完整回归。
- 验证器不复用或修改页面机器实例。
- 不发布、不打标签、不推送；发布由用户另行授权。
- 不提供完整规则载入或答案按钮；生产关卡数据不包含参考解答。
