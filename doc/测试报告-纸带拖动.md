### 拖拽语义说明（一处曾经误判）

鼠标**向左**拖时，纸带**内容跟手左移**，视口相对右移，因此窗口中心**增大**（`-8 → -4`）。
这是「抓住纸带跟手」的标准拖拽物理。首次编写验证脚本时断言写反了方向
（期望 `-4` 而非 `+4`），经复核确认为**脚本断言错误，非被测代码缺陷**，修正脚本后通过。

## 五、结论与遗留

- 纸带拖动功能**通过全部自动化与真实浏览器验证**，无控制台错误，行为符合设计文档。
- 与设计文档的一处差异已在计划文档中注明：`.tape { cursor: grab }` 后来演进为
  `.tape.can-drag { cursor: grab }`（抓手只在「随意拖动」模式出现，更符合语义）。
- **未覆盖**：触摸 / 触控笔输入（代码用 pointer 事件统一处理，理论上等价，
  但本轮未在真实移动设备上实测）；移动端布局下的拖动体验未验证。
