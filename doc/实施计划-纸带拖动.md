# 实施计划 — 纸带可鼠标左右拖动（feature: draggable-tape）

- **目标**：让图灵机实验台纸带支持鼠标左右拖动平移，初始停在位置 0，且不破坏现有逻辑。
- **执行原则**：遵循 `plan-driven-frontend-dev` —— 先规划、每逻辑单元一 commit、跑测试、写测试报告、即时 push。
- **拆分约束**：纯函数/接口先 → 独立交互模块 → 主程序集成 → 样式 → 文档独立。
