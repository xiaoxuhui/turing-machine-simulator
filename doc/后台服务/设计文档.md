# 后台服务设计

- 日期：2026-10-28；状态：已实施。
- 此前 Vite 直接在临时 exec 命令中运行，用户中断后监听端口与命令会话均消失。
- Node 启动脚本通过 detached + unref 启动独立隐藏 Node/Vite；调用者不等待进程退出，输出和错误分别写入日志。最初尝试的 PowerShell 文件受本机执行策略阻止，已改为 Node，不修改执行策略。
- 启动前请求现有页面并核对主入口；已就绪时直接复用。非本应用端口占用报错。启动后短时轮询确认就绪。
- 后台启动需要在可持续进程环境中执行；助手本次使用独立于临时执行会话的启动环境，并从后续命令再次检查进程和网页。
