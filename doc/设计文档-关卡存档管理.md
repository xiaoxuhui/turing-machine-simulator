# 关卡存档管理设计

## 数据格式

备份为 `{ format: "turing-machine-campaign", version: 1, exportedAt, progress }`。`progress` 继续使用现有 `{ version: 1, completedLevelIds, drafts }`，以兼容原有 localStorage 存档。

## 模块

- `src/campaign-backup.ts` 提供纯函数编码与严格解析；解析失败抛出可显示的错误，不执行部分导入。
- `src/campaign-main.ts` 提供下载、文件选择、确认导入、确认清空；导入先解析，再确认，再写本地存储并渲染。
- 清空先成功移除 localStorage 键，再替换内存进度；存储失败时保留当前数据并显示错误。
- 下载备份通过 Blob URL 和临时链接完成，不发往服务器。

## 界面

关卡页顶部加入“存档管理”工具条：保存备份、导入备份、一键清空。说明备份包含规则草稿；旧存档缺少的规则不能恢复。
