# 规则错误定位：需求与测试用例

日期：2026-10-30。用户要求：指出错误行，该行标红，并显示原因。

- U01：实验台和关卡规则编辑器实时显示解析错误，错误行红色背景；多处错误逐条列出行号和原因。
- U02：点击错误消息定位并选中对应行，滚动到可见区域；手动滚动和调整高度后标记仍对齐。
- U03：修复后立即移除对应红色和过期错误。保留草稿、原生编辑及撤销、函数缩进等现有行为。
- U04：没有行号的全局错误只显示原因，不标记任意一行；错误文本按纯文本处理。
- U05：对用户遇到的 `0,l->1,l.L` 给出逗号分隔写入与方向的提示；有效函数简写不误报。
- U06：大程序只创建错误行标记，不复制整份源码构造背景；长行横向滚动，避免软换行造成定位偏移。
