# 规则错误定位：设计文档

共享诊断组件包装原 textarea，在其可视内容区覆盖透明红色背景条。背景条按逻辑行号、实际字体行高、内边距、scrollTop 定位，无 pointer 事件，不修改编辑内容。规则编辑器 wrap=off，每条源码行对应一行。ResizeObserver 和 scroll 事件同步标记。

复用实验台 renderRuleTable 和关卡 updateRuleRecognition 已有的解析结果，避免重复编译。错误列表采用 button/textContent，点击按行计算 selection 范围并滚动；aria-invalid、aria-describedby 表达错误关联。无行号消息仅显示文本。

解析器对疑似使用点号分隔写入/方向的规则补充具体提示，保留其它既有行号及函数语义。
