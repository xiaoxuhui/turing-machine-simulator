# 实施计划：关卡重置与撤销

- **Status**: COMPLETE
- **Approved**: 2026-10-03 用户在对话中确认（选择「任意关可撤销 + 解锁改前沿式」）
- **Type**: feature
- **目标版本**: v0.5.1（未发版，待授权）

## 背景

关卡页目前没有任何撤销能力：玩家的规则草稿一旦改动就无法恢复初始提示，通关记录也无法取消。
本次加入「重置本关」与「撤销通关」，并把解锁判定改为前沿式，使撤销不会把已经走到的关卡重新锁死。

按项目纪律：**不发布、不打标签、不推送**。
