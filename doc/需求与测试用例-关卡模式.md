# 图灵机实验台：关卡模式需求与测试用例

## 文档状态

- 目标版本：v0.4.0
- 状态：实施中
- 日期：2026-09-27
- 实施策略：在现有实验台上增加独立模式，不改变自由实验、项目 JSON v1 与安卓外壳行为

## 目标

玩家在关卡模式中阅读目标、编写图灵机并提交验证。程序必须通过该关卡的全部测试输入才能完成关卡；完成后保存进度并解锁下一关。

## 用户流程

1. 点击顶部“关卡模式”，查看关卡列表、目标、输入输出示例和规则。
2. 只能进入第一关或已经解锁的关卡；点击“载入起始模板”将关卡初始配置放入现有编辑器。
3. 玩家继续使用现有规则文本、结构化规则表、单步和运行功能调试。
4. 点击“验证闯关”，系统在内存中用当前机器依次运行全部公开测试，不改变当前可视纸带。
5. 全部通过时标记完成、保存进度并解锁下一关；失败时显示首个失败输入、实际输出或超步原因。
6. 切回“自由实验”时，关卡面板隐藏，原有功能和项目保持可用。

## 关卡规则

- 首版提供 5 关：写下第一个 `1`、一进制加一、清空一进制、二进制逐位取反、二进制加一。
- 每关包含多个测试输入，避免只针对示例输入硬编码。
- 验证使用当前空白符、初始状态、终止状态和转移规则；测试输入由关卡覆盖。
- 机器必须在关卡步数上限内停止，且去除两端空白后的纸带内容与目标完全一致。
- 缺少转移规则、接受、拒绝或普通停机均视为“已停止”；是否通关只由步数上限和输出目标决定。
- 解锁顺序固定。已完成关卡可以反复进入和验证。
- 进度单独保存在 `turing-machine-simulator.campaign.v1`，不写入项目 JSON。

## 单元测试用例

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| U01 | 第一关模板在空纸带运行 | 输出 `1`，验证通过 |
| U02 | 一进制加一规则验证 `1/11/111` | 三项全部通过 |
| U03 | 规则只对一个示例正确 | 返回首个失败用例和期望/实际输出 |
| U04 | 非停机规则超过关卡上限 | 返回 step-limit，不阻塞页面 |
| U05 | 完成第一关 | 完成集合包含第 1 关，解锁第 2 关 |
| U06 | 读取损坏或未知关卡进度 | 忽略无效项并安全回退 |
| U07 | 从最后一关继续解锁 | 不产生不存在的关卡 ID |
| U08 | 验证过程 | 不修改页面当前机器实例和纸带 |

## 非目标

- 首版不提供账号、云同步、排行榜、计时竞速或自定义关卡编辑器。
- 首版不隐藏测试用例，也不以规则数量或运行步数评星。
- 本轮不迁移项目 JSON，不更改自由实验默认启动流程。
